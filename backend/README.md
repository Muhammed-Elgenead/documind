# DocuMind API

Backend of [DocuMind](https://github.com/muhammedTayallah/documind): upload PDF/DOCX/Markdown, ask questions, and get streamed answers where every claim cites the exact document and page.

The settings above are for Hugging Face Spaces. This folder is pushed to the Space by `.github/workflows/deploy-hf.yml`. Interactive API docs are at `/docs`.
